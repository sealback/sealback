How it works

  1. Create a key. The key file stays on your computer.
  2. Send the link to the person who has the secret.
  3. They encrypt the secret and email it to you. You decrypt it here.

Create a new key for each exchange and delete it afterwards.

Shown to the sender.

For long-lived or highly sensitive data.

How does this work?

Sealback uses age, an open and widely used encryption format.

Classical keys use X25519. Post-quantum keys combine ML-KEM-768 with X25519.

Nothing you enter is sent anywhere.
